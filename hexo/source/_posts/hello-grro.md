This blog is built with [Hexo](https://hexo.io) and is running on Grro. Every post is a Markdown
file in `source/_posts/`. Grro builds the site with `hexo generate` and serves the `public/`
folder with nginx.

## Write a new post

```sh
npx hexo new "My first post"
```

That creates `source/_posts/My-first-post.md`. Edit it, commit, push, and Grro rebuilds the site.

## Preview locally

```sh
npm run server
```
